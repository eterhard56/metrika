# Метрика Недвижимость

Сайт агентства недвижимости **Метрика** (Оренбург): каталог квартир с сортировкой, контакты и ссылки на Avito / VK / 2ГИС.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion

## Локально

```bash
npm install
npm run dev
```

## Деплой

Vercel: подключите репозиторий или выполните `npx vercel --prod`.
